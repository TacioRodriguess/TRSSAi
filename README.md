# 🤖 TRSS AI Coder

Um assistente de **IA focado em programação Python**, desenvolvido com **Streamlit** e integrado à API da **Groq**.  
O objetivo do TRSS AI Coder é ajudar desenvolvedores iniciantes a aprender e tirar dúvidas sobre programação em Python, fornecendo **explicações claras, exemplos de código comentados e referências oficiais**.

---

## 🚀 Funcionalidades

- Interface interativa construída com **Streamlit**.
- Chat em tempo real para tirar dúvidas sobre **Python**.
- Respostas estruturadas em:
  1. **Explicação clara** sobre o conceito.
  2. **Exemplo de código em Python** com comentários.
  3. **Detalhes do código** explicando cada parte.
  4. **📚 Documentação de Referência** com links oficiais.
- Histórico de mensagens mantido durante a sessão.
- Integração com a **Groq API** para geração de respostas inteligentes.

---

## 🛠️ Tecnologias Utilizadas

- [Python](https://www.python.org/)
- [Streamlit](https://streamlit.io/)
- [Groq API](https://console.groq.com/keys)

## 📦 Instalação e Uso

### 1. Clone o repositório
git clone https://github.com/TacioRodriguess/TRSS-AI-Coder.git
cd TRSS-AI-Coder 

### 2. Crie um ambiente virtual (opcional, mas recomendado)
python -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows

### 3. Instale as dependências
pip install -r requirements.txt

### 4. Configure sua API Key da Gro
- Obtenha sua chave em: Groq Console
- Insira a chave na barra lateral do aplicativo.

### 5. Execute o aplicativo
streamlit run app.py
